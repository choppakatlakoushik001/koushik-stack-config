# Koushik Stack

My terminal, editor and local-tooling setup (Alacritty, tmux, Neovim on Ubuntu/WSL, with local AI tooling on top): the configs I run, plus notes on what I changed and measured.

Files under `backup/` keep their local names and contents. I have left out credentials, personal projects, runtime state, raw logs, databases, model files, downloaded toolchains, and source code owned by other people.

The `showcase/` folder holds short notes about how the setup fits together, the changes I made, and the measurements I kept.

`MANIFEST.sha256` records a checksum for every included file except the manifest itself.
